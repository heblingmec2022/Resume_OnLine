# CV Online

Site pessoal e portfólio profissional de Pablo Hebling Guimarães, com foco em Dados, Business Intelligence, análise de negócios e experiências em projetos de tecnologia.

## Conteúdo

- `index.html`: resume online, perfil profissional, habilidades, experiências, formação e contato.
- `portfolio.html`: experiências profissionais em infraestrutura, suporte de TI e sistemas ERP.
- `carta-apresentacao.html`: carta de apresentação para oportunidades em Dados, BI e Negócios.
- `certificados.html`: tabela pública de cursos e certificações.
- `css/main.css`: estilos compartilhados, paleta visual e responsividade.
- `js/cv-modern.js`: menu responsivo e animações de entrada.
- `images/`: imagens utilizadas no site.
- `cv/`: arquivos PDF do currículo.

## Tecnologias

- HTML5
- CSS3
- JavaScript
- Layout responsivo
- Content Security Policy

## Como executar

Por ser um projeto estático, não é necessário instalar dependências. Basta abrir o arquivo `index.html` no navegador.

Para executar com um servidor local, por exemplo com Python:

```bash
python -m http.server 8000
```

Depois, acesse:

```text
http://localhost:8000
```

## Personalização

Os textos das páginas podem ser editados diretamente nos arquivos HTML. Para alterar cores, espaçamentos ou componentes visuais, edite as variáveis e regras em `css/main.css`.

Novos certificados devem ser adicionados como novas linhas na tabela de `certificados.html`, mantendo a ordem do ano mais recente para o mais antigo.

## Publicação

O projeto pode ser hospedado em qualquer serviço compatível com arquivos estáticos, como GitHub Pages, Netlify, Vercel ou um servidor web tradicional. Basta publicar os arquivos mantendo a estrutura de pastas.
